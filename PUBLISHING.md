# Publishing

The project uses [GitHub Pages](https://akshit98.github.io/business-process-ai-automation-case-study/). The deployment workflow reads the source and publishes the static `dist/` directory.

Edit the static files in `dist/`, then update the supporting analysis and PDF downloads. Pushes to `main` trigger publication. Check the latest GitHub Actions run before sharing a new revision; a committed file is not proof of successful deployment.

The portfolio contains independent analysis and proposed solutions. Keep source facts, hypotheses, and illustrative pilot targets clearly separated in future updates.
