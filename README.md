# Consulting Client Delivery Workflow Optimization & AI Automation

**Akshit Didla · Independent portfolio project · Process analysis and solution design · 2026**

[Portfolio website](https://akshit98.github.io/business-process-ai-automation-case-study/) · [Executive summary](case-study/Akshit_Didla_Executive_Summary.pdf) · [Full case study](case-study/Akshit_Didla_Workflow_Case_Study.pdf)

## What I did

I analyzed a supplied consulting-operations discovery transcript and mapped the current process from lead intake to invoicing. My original response documented stakeholders, systems, information gaps, discovery questions, workflow exceptions and improvement opportunities. This portfolio develops that work into a proposed future state, acceptance criteria, KPIs and an implementation roadmap.

## Completed artifacts

- Nine process stages with proposal revision loops, urgent starts, PM/partner assignment routes, alternate update channels and separate billing paths.
- Fifteen follow-up discovery questions and seven issue assessments separating facts from root-cause hypotheses.
- Five prioritized process, automation and AI opportunities with dependencies and review controls.
- Seven proposed requirements, eight planned acceptance tests and six KPI definitions.

These counts describe the work products, not measured business outcomes.

## My recommendation

Agree record ownership, setup readiness, assignment reconciliation and hourly time cutoffs first. Use rules for structured actions, retain authorized exception paths, and pilot AI only for proposal and status drafts that a person can verify.
